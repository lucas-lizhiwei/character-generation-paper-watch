## 新发现

### 1. Visual Persona: Foundation Model for Full-Body Human Customization

- **论文链接**：https://arxiv.org/abs/2503.15406
- **项目链接**：https://cvlab-kaist.github.io/Visual-Persona/
- **代码链接**：https://github.com/cvlab-kaist/Visual-Persona
- **Demo / 模型权重链接**：预训练权重通过 README 中的 Google Drive 链接提供；未发现在线 demo
- **发布时间或首次发现时间**：论文 2025-03-19；CVPR 2025；本追踪首次补录 2026-07-06
- **相关性等级**：强相关，相关性评分 3/5
- **研究问题概述**：给定单张人物参考图，生成多样化、文本可控的全身人物图像，同时保持脸、服装、体型、鞋子和配饰等全身身份细节。
- **方法亮点**：核心价值在 full-body identity preservation，不只保持脸；官方 README 明确支持 pose-guided generation、multi-scene story generation、text-guided virtual try-on 和 anime / character customization。
- **与 Stable Diffusion / LDM 的关系**：属于扩散模型个性化 / 参考图条件生成路线；官方 README 说明项目基于 IP-Adapter，并提供 ControlNet 推理脚本。
- **与 Text-to-Live2D / 动漫角色建模的关系**：不生成 Live2D 层或绑定结构，但对“单参考角色 -> 多姿态 / 多场景 / 风格化角色素材”的一致性控制很有参考价值，可作为 Textoon / See-through 前后的角色一致性模块参考。
- **代码状态总结**：官方推理代码 + 预训练权重；README 提供 `inference.py`、`inference_controlnet.py`、`inference_controlnet_story.py`、`inference_tryon.py`、`inference_anime.py` 和 parsing 脚本；未看到完整训练代码。
- **为什么值得关注**：它把 IP-Adapter 方向从脸部身份扩展到全身外观，对动漫角色换装、姿态控制、角色设定图扩展很有迁移价值。

> 注：这是历史补录，不是 2026-06-29 至 2026-07-06 之间首次公开的新论文。本周未发现可确认的直接 Text-to-Live2D / Live2D 分层角色生成新论文。

### 1. See-through 工具链生态更新：Anime2.5DRig 加入社区支持列表

- **相关项目**：See-through: Single-image Layer Decomposition for Anime Characters
- **论文链接**：https://arxiv.org/abs/2602.03749
- **代码链接**：https://github.com/shitagaki-lab/see-through
- **更新链接**：https://github.com/shitagaki-lab/see-through/commit/0e19fa2fd977bc5536249f2dcd712629227498e1
- **更新时间**：2026-07-04
- **更新内容**：See-through README 将 Anime2.5DRig 加入 community support。Anime2.5DRig 是第三方浏览器工具，可把分层 PSD 自动转换为 2.5D VTuber 风格 avatar，支持眨眼、口型、头发物理，并说明其图层命名基本遵循 See-through PSD 约定。
- **代码状态总结**：See-through 仍是官方完整开源；Anime2.5DRig 是第三方工具，不包含 See-through 模型或代码，不做单图分层，只负责 PSD 后处理 / 自动 rig。
- **为什么值得关注**：这条更新强化了 “See-through 分层 PSD -> 自动 rig -> 可驱动 2.5D avatar” 的工具链闭环，是最接近 Live2D 制作流程自动化的实用进展。

## 趋势观察

1. 本周没有新的直接 Text-to-Live2D / image-to-Live2D / 动漫分层角色生成论文。主线仍由 Textoon、See-through、CartoonAlive 三个核心基线支撑。
2. 角色一致性方向仍然值得押注。Visual Persona 虽然不是动漫 / Live2D 专用，但它把参考人物的全身外观、服装、体型和配饰纳入一致性目标，对角色设定图、多姿态素材和换装编辑非常有参考价值。
3. 工具链侧比论文侧更活跃。See-through 周边已经出现 StretchyStudio、Anime2.5DRig、Paper Doll Studio 等后处理 / rig / wardrobe 项目，说明 “先生成或分解 PSD，再自动 rig / 自动服装编辑” 可能比端到端 Text-to-Live2D 更快形成可用实验闭环。
4. Talking avatar 论文数量继续增长，但多数是 3D / real-human portrait / audio-driven face motion，对 Live2D 的直接帮助有限。可迁移点主要在实时口型、表情强度、缓存加速和多人对话交互，而不是角色建模本体。
5. 代码开放情况仍不理想。AnimeAdapter 未开源，CartoonAlive 仍是占位型仓库；本周真正有复现价值的变化主要来自 See-through 生态和 Visual Persona 的已开放推理代码。
