## 新发现

### 1. DreamShot: Personalized Storyboard Synthesis with Video Diffusion Prior

- **论文链接**：https://arxiv.org/abs/2604.17195
- **项目链接**：https://ll3rd.github.io/DreamShot/
- **代码链接**：https://github.com/dihy16/DreamShot-Code
- **Demo / 模型权重链接**：https://huggingface.co/LL3RD/DreamShot
- **发布时间或首次发现时间**：论文 v1 为 2026-04-19；v2 于 2026-07-06 修订并标注 CVPR 2026 Highlight；本追踪首次记录为 2026-07-13。
- **相关性等级**：强相关，相关性评分 3/5。
- **研究问题概述**：面向 storyboard / 多镜头视觉叙事生成，目标是在多个镜头之间保持角色身份、场景和叙事连续性。它不是 Live2D 或动漫角色建模论文，但直接处理多角色参考一致性和跨镜头连续性。
- **方法亮点**：基于 video diffusion prior 做 Text-to-Shot、Reference-to-Shot 和 story continuation；引入 multi-reference role conditioning，并用 Role-Attention Consistency Loss 约束参考角色与生成角色的身份对齐。
- **与 Stable Diffusion / LDM 的关系**：不是 Stable Diffusion 主线，使用视频生成模型先验；官方 README 说明推理可结合 LightX2V 的 step-based LoRA distillation 加速。
- **与 Text-to-Live2D / 动漫角色建模的关系**：不输出 Live2D 图层、绑定结构或 2D 角色模型；但对生成同一角色的多姿态、多镜头参考素材有启发，可作为 Textoon / See-through 后续“角色一致性素材生成”分支参考。
- **代码状态总结**：官方推理代码 + Hugging Face 模型权重已公开；数据集因电影数据合规审核暂未发布；训练代码计划在数据集发布后再开放。
- **为什么值得关注**：它把角色一致性从单图/单镜头推进到多镜头叙事生成，对构建角色设定图、表情/动作素材和连续动画分镜很有参考价值。

## 趋势观察

- 本周没有发现新的、可确认的直接 Text-to-Live2D / Live2D 分层动漫角色生成论文。核心主线仍由 Textoon、CartoonAlive、See-through 这几条历史项目支撑。
- 近期更活跃的是“角色一致性视频 / 多镜头叙事 / 实时交互 avatar”方向。DreamShot、Vidu S1 都把角色从静态图像推进到多镜头或实时视频，但它们不解决 Live2D 的图层、网格、参数和 Cubism 导出问题。
- Stable Diffusion / SDXL 在直接 Live2D 生成中仍重要，尤其是 Textoon 和 See-through 这类管线；但新的视频角色工作更多转向 Wan / video diffusion / streaming diffusion / 自研实时视频生成系统。
- LoRA 仍然作为加速或适配工具出现。DreamShot README 明确提到可结合 LightX2V 的 4-step LoRA distillation 加速推理，但它不是传统 SD LoRA 角色个性化路线。
- 对当前研究最有启发的方向是“可编辑中间表示 + 角色一致性生成”合流：See-through 负责分层与可编辑 PSD，DreamShot 这类工作负责跨镜头角色一致性，两者如果结合，可能形成从文本/参考角色到多姿态、多表情、可分层素材包的更完整路线。
