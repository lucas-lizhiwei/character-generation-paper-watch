## 重要更新

### See-through: Single-image Layer Decomposition for Anime Characters

- 论文链接：https://arxiv.org/abs/2602.03749
- 项目链接：
- 代码链接：https://github.com/shitagaki-lab/see-through
- Demo / 模型权重链接：
  - https://huggingface.co/spaces/24yearsold/see-through-demo
  - https://modelscope.cn/studios/ljsabc/See-Through
  - https://huggingface.co/layerdifforg/seethroughv0.0.2_layerdiff3d
- 论文首次公开时间：2026-02-03
- 相关性等级：核心相关
- 相关性评分：5/5
- 研究问题概述：
  - 从单张动漫角色图像自动生成可操作的 2.5D 分层结果，减少 Live2D 前处理中的手工分层和遮挡补全成本。
- 方法亮点：
  - 将角色分解为最多 23 个语义层，并结合 diffusion-based body part consistency 与 pseudo-depth 推断绘制顺序。
  - 训练监督来自商业 Live2D 模型解析得到的高质量语义和隐藏几何信号。
- 与 Stable Diffusion / LDM 的关系：
  - README 明确给出 LayerDiff 3D 为基于 SDXL 的透明分层生成模型。
- 与 Text-to-Live2D / 动漫角色建模的关系：
  - 与 Live2D 方向高度贴合，直接产出分层 PSD，可服务于后续部件拆分、编辑和动画制作。
- 代码状态总结：
  - 官方；有推理；有训练；有 Demo；有模型权重。
- 为什么值得关注：
  - 这是当前最接近“图像到 Live2D 可编辑结构”的公开工作之一，且工程完成度已经明显高于仅有论文的同类项目。

## 趋势观察

- 今天这轮扫描表明，真正直接服务于 Text-to-Live2D 的公开新工作仍然偏少，更多工作集中在角色一致性、角色表演视频和 3D animatable asset。
- Stable Diffusion / LDM 仍然是与角色控制最接近的实用底座，但新工作里也能看到更多 flow-matching 或 DiT 系路线。
- 与你的主线最贴近的仍是“分层角色表示 + 可编辑输出结构”这一类工作；See-through 是当前最值得优先深挖和复现实验的对象。
- 代码开放情况相较仅论文阶段有改善，但很多项目仍停留在项目页或占位仓库层面，真正提供训练与推理全链路的项目依然稀缺。
