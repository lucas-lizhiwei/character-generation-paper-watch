# Character Generation Paper Watch

A research tracker for papers, projects, demos, and code related to:

- AI generative character modeling
- Text-to-Live2D
- Anime character generation
- 2D / 2.5D digital humans
- Stable Diffusion-based character generation
- Controllable character editing
- Layered character representation
- Live2D-ready asset generation

---

## Scope

This tracker focuses on research related to:

- text-to-character generation
- text-to-anime character generation
- text-to-Live2D
- image-to-Live2D
- layered character generation
- controllable character editing
- character consistency in diffusion models
- ControlNet / LoRA / IP-Adapter for character control
- pose-guided character generation
- expression-guided editing
- animatable 2D / 2.5D avatar generation
